Featured project

CollabEdit — real-time documents, built from scratch

A Google Docs–style editor with live cursors, offline editing, version history, full-text search and link sharing. I wrote the sync server, storage and auth myself on FastAPI, Yjs/pycrdt, PostgreSQL and Redis, and run it on free-tier hosting.

Own CRDT sync server

FastAPI WebSockets speak the Yjs sync and awareness protocols over pycrdt (Rust Yrs): one room per open document, per-connection send queues, and roles enforced on every update. Edits reach other users in about 110 ms in production.

Edit log + compaction

Every edit lands in an append-only Postgres log, batched every 500 ms, then folds into snapshots under an advisory lock. Opening a 10,000-keystroke document went from 218 ms to 17 ms.

Self-built rate limiter

A token bucket in a single Redis Lua script: atomic across API instances, in one round trip, with fail-open or fail-closed per policy.

Careful sessions

Argon2id passwords, 15-minute JWTs, rotating refresh tokens with reuse detection, and one-time 30-second WebSocket tickets.

Offline-first

The browser keeps an IndexedDB copy of each document; edits made offline merge automatically when the connection comes back.

Tested and documented

173 API tests against real Postgres and Redis — including Hypothesis convergence properties — plus 79 web tests, and 10 architecture decision records.
